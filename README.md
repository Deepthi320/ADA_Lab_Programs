# ADA Lab Programs

This repository contains Java implementations of Design and Analysis of Algorithms (ADA) laboratory programs completed as part of the 4th Semester Computer Science curriculum.

## Programs
- Selection Sort
- Insertion Sort
- Quick Sort
- Merge Sort
- Prim's Algorithm
- Kruskal's Algorithm
- Dijkstra's Algorithm
- Floyd's Algorithm
- 0/1 Knapsack
- Subset Sum
- N-Queens
- Topological Sort

Language: Java
